Camera detections to the cloud

A modified YOLOv5 detect.py uploads frames with detections to Firebase Storage for the app's Camera Feed.

def take_photo_and_upload(image_name, image):
    # Save the image locally
    cv2.imwrite(image_name, image)

    # Upload image to Firebase Storage
    bucket = storage.bucket()
    blob = bucket.blob(image_name)
    blob.upload_from_filename(image_name)
